# Playground

The demo playground is a multi-route manual QA app that compares:

- with package (`@kerothebosa/ui-skeleton-net` active)
- without package (same UI/request flow, no skeleton enhancer)

## Run Locally

```bash
npm run demo:dev
```

Open:

```text
http://127.0.0.1:4174/#/overview
```
