# Security Policy

## Supported Versions

Security updates are provided for the latest release line.

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |
| < 0.1.0 | No        |

## Reporting a Vulnerability

Please report security issues privately and do not open a public GitHub issue.

- Email: `security@skeleton-ui.dev`
- Include:
  - affected version
  - reproduction steps or proof of concept
  - expected vs actual behavior
  - impact assessment if known

### Response Expectations

- Initial acknowledgment: within 3 business days
- Triage update: within 7 business days
- Fix timeline: depends on severity and complexity

If the report is confirmed, we will coordinate a fix and disclosure timeline
before public release notes are published.
